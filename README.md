# 📊 Cálculo de Promedio y Calificaciones en Java

Repositorio correspondiente a la Actividad 6 de la materia de Computación en Java.

## 📝 Descripción del Proyecto
El programa implementa una clase en Java que utiliza un arreglo de cinco calificaciones, un método para calcular el promedio, un método con estructura de decisiones (`if-else`) para asignar una letra según los rangos establecidos, y un método final para imprimir los resultados en consola con un formato específico.
